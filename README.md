# Vinayak Tripathy — Animated Portfolio 🚀

An animated personal portfolio website built with React, TypeScript, GSAP, and Three.js featuring a 3D character, WebGL visuals, and smooth scroll animations.

## ✨ Features

- 3D animated character (React Three Fiber + Rapier physics)
- GSAP scroll-triggered text reveal animations
- Custom cursor, loading screen, and marquee effects
- Responsive layout

## 🛠️ Tech Stack

React • TypeScript • Vite • GSAP • Three.js • React Three Fiber • WebGL • CSS

## 🚀 Getting Started

```bash
npm install
npm run dev      # local dev server
npm run build    # production build
npm run preview  # preview production build
```
